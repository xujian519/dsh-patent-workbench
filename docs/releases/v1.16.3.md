## 3. 逐条变更

### 3.1 侧栏入口文案

`ENTRY_TITLE = '专利工作台'`。宿主对 `sidebar.panellist` 行的 `label` 直接渲染为行文案与 `aria-label`，所以 Web 与桌面 App **同源同改**，不存在两套文案。

### 3.2 标题栏按钮 `title` 收敛

`title={active ? '收起工作台' : ENTRY_TITLE}`：去掉硬编码副本。折叠态文案「收起工作台」保持不变。

## 4. 破坏性变更

无。纯展示文案；数据、schema、路由、工具签名均未变。

## 5. 依赖边界
