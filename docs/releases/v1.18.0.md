## 2. 送达方式不再默认电子送达（`92a52b6`）

对齐宪法 EX-2026-001 / `docs/constitution-alignment.md` §一：

- 迁移 26：`matter_notices.delivery_mode` **可空、无 DEFAULT**；NULL = 未登记。
- 仓储省略/空白 → 中文报错不落库；适配层不把缺送达的官文送进引擎。
- 登记表单不预选；列表显示「送达方式未登记」。
- 同批：重算要求显式 `today`；预备案卷禁止进入期限计算。

设计稿 `docs/design/2026-10-03-patent-workbench-redesign.md` 中阶段 2 SQL 的 `DEFAULT 'electronic'` 为**历史 DDL**，已加订正脚注；以 `src/db/schema.ts` 为准。

## 3. ADR-001 工作根（PR #7）

- 工作根唯一实现 `src/shared/workRoot.ts`（默认 `~/工作`，覆盖 `DSH_WORK_ROOT`）。
- 扫描/bootstrap 对齐；落库只写索引 + `workspace_path`；拒绝正文类字段写入。
- 本仓 ADR 指针：`docs/adr/0008-matter-folder-index.md`；权威在 sibling `dsh-patent` ADR-001。

## 4. 破坏性变更

- **行为**：省略送达方式不再静默变电子送达；可能使历史上「没填也算出期限」的路径变为 pending/拒收——这是偿还，不是回归。
- **无**强制数据回填：存量 `'electronic'` 行保留。
